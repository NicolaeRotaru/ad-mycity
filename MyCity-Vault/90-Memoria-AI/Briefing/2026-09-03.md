per tutti e due.

### Perché la macchina sembra ferma e non lo è

Il server lavora ma non pubblica: il giro prova prima il rebase, poi il merge su `origin/main`, e
tutti e due si fermano sul conflitto degli 8 file. Il motore AI gira lo stesso (`ai_rc=0`), scrive in
locale, e la pubblicazione finale fallisce (`SERRATURA`, `STASH` fra gli 11 vincoli). Il repo su GitHub
resta fermo al 1/9 12:15 e ogni controllo che legge git, compresa la mia visita, vede una macchina
morta. È lo stesso schema del 21/8 (card #150): commit locali mai pubblicati che divergono da `main`.

Comandi per il server, nella card #168:

```bash
cd "$(systemctl show -p WorkingDirectory --value mycity-worker)"
git log --oneline origin/main..HEAD | wc -l          # quanti commit locali non sono mai arrivati su GitHub
git push origin HEAD:refs/heads/memoria/vps-2026-09-03   # li mette al sicuro su un ramo, senza toccare main
git diff --stat HEAD -- cervello/worker.sh            # cosa è diverso nel worker.sh «manomesso»
```
